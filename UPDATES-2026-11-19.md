# Updates — 2026-11-19

Summary of work done today on the regex web-scrape demo.

## Code (`web_scrape_regex.py` → v0.5)

- Extract **`canonical`**, meta **`keywords`**, and **phone**-looking strings.
- Add a tiny same-host **BFS crawl** via `--max-pages` (default `1` = single page).
- Offline mode includes a second sample page (`/relative`) so crawl can be demoed without the network.
- New CLI flags:
  - `--max-pages` — fetch up to N same-host pages
  - `--user-agent` — override the HTTP User-Agent
- `-o` now also writes a short **Markdown** report (`.md`).
- Multi-page results use a `pages` + `crawl` shape; CSV gets one row per page.
- Bump User-Agent version string to `0.5`.

## Tests (`test_web_scrape_regex.py`)

- Assert keywords, canonical, and phones on sample HTML.
- Cover offline `--max-pages 2` crawl (home → relative).
- Cover Markdown `write_output`.

## GUI (`scrape_gui.py`)

- First Tkinter front-end (stdlib): URL + offline/same-host/robots options, delay/timeout/max-pages/max-links, User-Agent.
- **Run** calls `crawl()` on a background thread so the window stays responsive.
- Results pane: human summary or JSON; **Save…** writes `.json` / `.csv` / `.md` via `write_output()`.
- Offline is checked by default for a safe manager demo.
- Helpers (`build_crawl_kwargs`, `format_result`) import without Tk so unit tests still pass on Homebrew Python builds that lack `_tkinter`.
