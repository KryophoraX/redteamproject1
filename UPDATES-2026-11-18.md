# Updates — 2026-11-18

Summary of work done today on the regex web-scrape demo.

## Code (`web_scrape_regex.py` → v0.4)

- Extract **`og:url`** and **image `src`** values (images resolved against the page base URL).
- Add page **`stats`**: word count, character count, link count, image count, email count.
- Strip `<script>` / `<style>` before counting visible-ish text.
- New CLI flags:
  - `--timeout` — HTTP timeout seconds
  - `--max-links` — cap length of each link list
  - `--same-host` — keep only resolved links on the same host as `--url`
  - `-q` / `--quiet` — skip human-readable stdout (useful with `-o`)
- Refactor human-readable printing into `print_human()`.
- CSV export now includes `og_url`, `images`, and stats columns.
- Sample HTML expanded with `og:url` and an `<img>` for offline demos.

## Tests (`test_web_scrape_regex.py`)

- Assert `og_url`, images, and `stats.word_count`.
- Cover `--same-host` + `--max-links` behavior.
- Cover JSON/CSV `write_output`.
- Smoke-test CLI via `main(["--offline", ...])`.
